# Código de conducta

Lost & Prompt adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)
([English](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)).

En resumen: trata a todas las personas con respeto, sé amable con quien empieza, acepta las críticas
constructivas y céntrate en lo que es mejor para la comunidad. No se toleran el acoso, los insultos
ni los ataques personales.

Para reportar un comportamiento inaceptable, escribe de forma privada al mantenedor mediante
[un aviso de seguridad privado](https://github.com/axchisan/lost-and-prompt/security/advisories/new)
o por mensaje directo en GitHub (@axchisan). Todos los reportes se revisan con confidencialidad.
