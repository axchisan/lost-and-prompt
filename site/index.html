Lost & Prompt
FuncionesFeatures InstalarInstall GitHub

Todas tus sesiones de Claude Code, en un solo lugar.Every Claude Code session you ever lost, found.

Claude Code guarda cada sesión en la carpeta donde la abriste. Lost & Prompt las reúne todas: búscalas por lo que se dijo, reanúdalas en tu terminal con un clic y organízalas a tu manera. Claude Code ties every session to the folder you opened it in. Lost & Prompt brings them all together: find them by what was said, resume them in your terminal with one click, and organize them your way.
