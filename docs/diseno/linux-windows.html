Linux y Windows: con qué construirlo

La versión de Mac está hecha en SwiftUI, que solo funciona en sistemas de Apple. Para Linux y Windows hay que elegir otra tecnología. Esta página compara las opciones y muestra cómo se vería la app con el mismo diseño.

Recomendación: Tauri 2 con un núcleo en Rust

Un solo código para Windows y Linux. La interfaz es web (HTML y CSS), así que se puede calcar el diseño de Mac columna por columna. La lógica pesada (leer las sesiones, el índice de búsqueda, reanudar en la terminal) va en Rust, igual de rápida que la versión Swift.

  • Instaladores nativos de serie: .msi y .exe en Windows; .deb, .rpm y AppImage en Linux.
  • Instaladores pequeños, de pocos MB, porque usa el navegador integrado del sistema en vez de empaquetar uno.
  • Trae lo que la app necesita: ícono en la bandeja, atajo global, actualizaciones automáticas, vigilar carpetas.
  • Tú ya trabajas con tecnología web (Next.js), así que podrás mantenerla.

A cambio, la interfaz no usa los controles nativos de cada sistema; hay que dibujarlos con CSS. Por eso la propuesta es la misma estructura, los mismos íconos y el mismo ícono de app que en Mac, con los detalles de cada sistema: Fluent y Mica en Windows 11, y el estilo de GNOME en Linux.

Así se vería en Windows 11

Las mismas tres columnas, los mismos textos y el mismo botón protagonista. Cambian la barra de título, la tipografía Segoe UI y el acento azul de Windows.

Íconos: los mismos en las tres plataformas

En Mac la app usa los SF Symbols de Apple, cuya licencia no permite usarlos fuera de sistemas de Apple. Para Windows y Linux propongo Lucide, un set de código abierto con el mismo estilo: trazo fino y uniforme, esquinas redondeadas y formas simples. Cada ícono de Mac tiene su equivalente directo, debajo de su nombre en SF Symbols.

Qué cambia respecto a Mac

Dónde viven las sesiones

  • Linux: ~/.claude/projects, igual que en Mac.
  • Windows: %USERPROFILE%\.claude\projects, y también las de cada distribución WSL si se usa Claude Code dentro de WSL.

Reanudar

  • Windows: Windows Terminal (wt -d <carpeta> claude --resume <id>), PowerShell o WSL.
  • Linux: la terminal elegida, cada una con su propia forma de abrir en una carpeta.
  • Warp existe en las dos plataformas.

Lo que se comparte

  • El formato de las sesiones, la lógica de búsqueda, colecciones, notas y la retención: se reescriben en Rust una vez.
  • Ese núcleo podría servir después para una herramienta de línea de comandos.
  • El diseño, los textos y las traducciones ya están definidos.
